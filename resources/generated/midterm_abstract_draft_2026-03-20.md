## 摘要（版本 A）

面向蛋白质设计任务的 LLM Agent 系统，往往存在执行链路隐式、失败恢复缺乏结构化控制以及人工干预难以审计的问题，导致系统虽然能够调用多种生物信息工具，却难以在真实研究场景中提供稳定、可追溯且可治理的执行过程。针对上述问题，本文设计并实现了一个基于显式有限状态机（FSM）的蛋白质设计多 Agent 系统。该系统以 Planner、Executor、Safety 和 Summarizer 为核心角色边界，以 Tool Knowledge Graph 和工具适配层为执行基础，将蛋白质 de novo 设计过程组织为规划、执行、安全审查、结果汇总与人机协同决策的统一闭环。与单次规划后直接执行的代理范式不同，本文系统在关键节点输出 Top-K 候选，并通过 `WAITING_PLAN_CONFIRM`、`WAITING_PATCH_CONFIRM` 和 `WAITING_REPLAN_CONFIRM` 等状态显式承载 Human-in-the-loop 决策；在执行阶段采用 `retry -> patch -> replan` 的分层恢复策略，并结合事件日志、任务快照与决策记录实现全过程可回放与可审计。围绕蛋白质设计工作流，系统进一步落地了覆盖序列探索、结构映射、质量门禁、结构条件精修、多目标打分与恢复控制的六阶段能力组织方式。当前实现已完成核心架构、状态流转、候选门禁、恢复机制、日志与快照持久化以及 API/UI 交互链路，并形成了功能验证、可用性验证和治理复核等阶段性证据。与此同时，本文已完成纵向增量实验与横向对比实验的设计、分组和指标口径定义，为后续系统效果评估与论文定稿提供基础。中期阶段的工作表明，该系统已经建立起面向蛋白质设计任务的可控执行与治理闭环，但横向对比结果与最终发布门禁仍有待后续实验进一步补齐。

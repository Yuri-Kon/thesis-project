\section{毕业设计（论文）内容概述}

\subsection{项目来源及开发目的和意义}

本节建议说明课题来源、研究背景、工程需求和论文选题意义。
可以直接围绕以下问题展开：

\begin{itemize}
  \item 当前蛋白质设计或 LLM Agent 系统存在哪些问题；
  \item 为什么需要显式 FSM、HITL 与恢复控制；
  \item 该课题对工程实现和研究验证的价值是什么。
\end{itemize}

\subsection{主要开发任务}

本节建议概述中期前需要完成的核心任务，例如：

\begin{itemize}
  \item 多 Agent 系统总体架构搭建；
  \item Planner / Executor / Safety / Summarizer 的职责落地；
  \item 六阶段工作流与恢复控制实现；
  \item ToolKG、工具适配器、日志和快照能力接入；
  \item 中期阶段的验证、实验设计和展示材料整理。
\end{itemize}

\subsection{本人所承担任务（模块）说明}

本节建议明确个人负责的模块与边界，例如：

\begin{itemize}
  \item 系统架构设计与核心工作流实现；
  \item 候选集决策、门禁与恢复机制；
  \item 实验脚本、验证报告与论文材料整理；
  \item 远端服务接入、展示链路与可审计能力建设。
\end{itemize}

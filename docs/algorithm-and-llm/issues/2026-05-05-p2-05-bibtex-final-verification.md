# Issue: P2-5 在论文定稿前完成 BibTeX 与参考文献最终核验

## 类型

- Priority: P2
- Scope: research / bibliography / publication readiness
- Phase: CEBRA-WP P2 文档与表达增强
- Body language: Chinese
- 状态：待实现
- 本文件定位：P2-5 的唯一实现参考来源；进入编码前以本文为准。

## 1. 背景

设计文档已经说明过：在当前阶段，部分文献检索可能受限于 API 限流或数据质量。因此论文定稿前必须做最终核验，不能只拿临时笔记当引用源。

## 2. 当前缺口

参考文献最终核验至少要补齐：

- DOI
- 会议/期刊版本
- arXiv 版本
- BibTeX key
- 是否保留 2026 预印本版本

## 3. 风险

如果不核验，最容易出的问题是：

- 引用 key 不稳定；
- 版本号不对；
- 同一工作被重复引用；
- 论文提交前临时补文献导致格式不一致。

## 4. 建议方案

在论文定稿前做一次集中核验，并把结果落到唯一文档：

```text
paper title -> canonical citation -> bibtex key -> version -> usage note
```

## 5. 最小实现提案

- 先列出论文候选清单；
- 再逐条核验元数据；
- 最后冻结 BibTeX 与正文引用。

## 6. 验证建议

1. 每篇关键论文都有唯一引用条目；
2. key 与版本号一致；
3. 文档中的引用能直接复制到论文。

## 7. 验收标准

- 论文参考文献可直接进入定稿；
- 不再依赖临时检索结果；
- 引用格式与版本信息一致。

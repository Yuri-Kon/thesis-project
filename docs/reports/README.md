# 论文阶段材料索引

更新时间：2026-05-07

本目录用于集中存放毕业论文撰写阶段的系统盘点、图表清单、验证证据索引等材料。当前材料优先服务于论文正文组织，不改变系统实现、不覆盖 `asserts/figures/` 中已经绘制和人工调整过的图示。

## 当前文档

| 文档 | 用途 | 建议使用位置 |
|:---|:---|:---|
| [system-feature-inventory.md](./system-feature-inventory.md) | 盘点系统现有功能、已完成模块、缺失或待补齐模块 | 第三章系统设计、第四章实现、第五章实验前的系统说明 |
| [thesis-figure-table-index.md](./thesis-figure-table-index.md) | 建立论文图、表清单，并标注来源、状态、正文位置 | 论文目录规划、图表编号整理、最终查漏补缺 |

## 维护约定

- 图示源文件仍以 `asserts/figures/*.drawio` 为准。
- 论文材料优先引用已存在的实现、设计文档和验证报告，避免在正文中写出尚未落地的能力。
- 若后续新增实验、截图、对比表或验证记录，优先补充到本目录中，再同步到论文正文。
